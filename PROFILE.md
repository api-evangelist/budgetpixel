## APIs

- **BudgetPixel REST API** — Credit-metered REST API (private beta) for programmatic access to 36+ AI image, video, and music models, plus content moderation, music-genre classification, format conversion, uploads, cost estimation, and community post publishing. Asynchronous job-based, Bearer API key auth. (`https://api.budgetpixel.com/v1`)
- **BudgetPixel MCP Server** — Hosted remote Model Context Protocol server enabling AI agents (Claude, ChatGPT, Cursor) to generate images, video, and music, upload files, browse the model catalog, check credit balance, view history, and publish community posts. Streamable HTTP transport with OAuth 2.1 / Google SSO auth. (`https://mcp.budgetpixel.com/mcp`)
