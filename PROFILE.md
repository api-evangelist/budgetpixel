## APIs

- **BudgetPixel REST API** — Unified REST API across image, video, music and sound-effect models with an async job model, cost estimation, moderation, conversions, and social publishing. Private beta; requires Premium/Pro/Ultra plans and a Bearer API key. (`https://api.budgetpixel.com/v1`)
- **BudgetPixel Product MCP Server** — Hosted Model Context Protocol server giving agents tools to generate images/video/music/SFX, upload references, check pricing and credits, and publish to the community feed. Google sign-in; generation gated to paid plans, catalog browsing open to any account. (`https://mcp.budgetpixel.com/mcp`)
- **BudgetPixel Docs Search MCP Server** — Read-only MCP server for searching the BudgetPixel documentation. (`https://docs.budgetpixel.com/mcp`)
