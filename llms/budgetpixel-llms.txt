# BudgetPixel API

> Programmatic image and video generation API for BudgetPixel.

- [BudgetPixel API](https://docs.budgetpixel.com/introduction.md): Generate images, video, music, and sound effects programmatically with the models you already use on BudgetPixel.
- [Quickstart](https://docs.budgetpixel.com/quickstart.md): Generate your first image in a few minutes.
- [Authentication](https://docs.budgetpixel.com/authentication.md): Authenticate requests with a bearer API key.
- [Pricing & credits](https://docs.budgetpixel.com/concepts/pricing-and-credits.md): How API usage is metered and billed in credits.
- [Rate limits](https://docs.budgetpixel.com/concepts/rate-limits.md): Request rate limits, response headers, and how to handle 429s.
- [MCP Server](https://docs.budgetpixel.com/mcp-server.md): Connect Claude, ChatGPT, Cursor, or any MCP-compatible agent to BudgetPixel and generate images, video, music, and sound effects from the conversation — no API key needed.
- [Async jobs](https://docs.budgetpixel.com/concepts/async-jobs.md): How generation jobs are created, polled, and completed.
- [Models](https://docs.budgetpixel.com/concepts/models.md): Discover available image, video, music, and sound-effect models and their pricing.
- [Media inputs](https://docs.budgetpixel.com/concepts/media-inputs.md): Provide an input image (or other media) for image-to-image and image-to-video models — by URL, upload, data URI, or base64.
- [Get credit balance](https://docs.budgetpixel.com/api-reference/account/get-credit-balance.md)
- [List available models](https://docs.budgetpixel.com/api-reference/models/list-available-models.md): Returns the models available via the API, with pricing.
- [Estimate the cost of a request](https://docs.budgetpixel.com/api-reference/models/estimate-the-cost-of-a-request.md): Returns the credit cost of a generation request **without running it**. Send the same body you'd send to the generate endpoint, plus `model`.
- [Upload input media](https://docs.budgetpixel.com/api-reference/uploads/upload-input-media.md): Upload an image, video, or audio file to use as input for a generation (e.g. the `image` param on an image-to-image or image-to-video request). Returns a short-lived `url` you pass as that media parameter.
